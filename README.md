# Простор

Удаление программ, очистка и анализ места на диске для Windows 10/11. Скачать — в [релизах](https://github.com/GuiltHC/Prostor/releases/latest): один файл `Prostor.exe`, устанавливать ничего не нужно. Приложение запускается, когда оно нужно, и полностью закрывается вместе с окном: значка в трее и фоновых процессов нет.

С версии 2.0 Простор написан на Rust с интерфейсом на [GPUI](https://www.gpui.rs) (через [gpui-kit](https://gpui-kit.com)). Версии 1.x на .NET обновятся до 2.0 сами, через встроенную проверку обновлений; настройки, журнал, история дисков и снимки сканирований остаются на месте.

## Возможности

**Обзор**
- Системный диск одним взглядом: сколько занято, сколько можно освободить и куда смотреть.
- История свободного места с прогнозом, когда диск заполнится.
- Состояние дисков (SMART через Windows Storage).
- Рекомендации: что можно освободить прямо сейчас.

**Программы**
- Классические программы, приложения Microsoft Store, игры Steam, Epic, GOG, EA, Ubisoft, Battle.net и Xbox в одном списке.
- Когда программу запускали последний раз (UserAssist, ярлыки «Пуск», Prefetch, Steam) и фильтр «Не используются».
- Метки: компонент (Visual C++, .NET и т. п.), драйвер, системная, предустановленная.
- Обновления через winget, кнопка «Обновить всё».
- Экспорт списка в CSV и в файл импорта winget.
- Точка восстановления перед удалением.
- Поиск остатков после удаления: папки, ключи реестра, задания планировщика, службы, ярлыки, автозагрузка, правила брандмауэра. Перед удалением ключи реестра и задания сохраняются в резервную копию.
- Принудительное удаление, если штатный деинсталлятор сломан или отсутствует.

**Анализ диска**
- Обычное сканирование и быстрое чтение MFT для целого диска NTFS (нужны права администратора): весь системный диск — за секунды.
- Карта папок с приближением и список содержимого рядом с ней (правый щелчок — открыть, сжать, перенести, в исключения, в корзину), типы файлов, список крупных файлов.
- «Что выросло» — сравнение с прошлым сканированием.
- Дубликаты: сравнение по размеру, затем по хэшу начала и конца, затем по полному SHA-256; жёсткие ссылки не считаются копиями.
- Старые файлы и старые загрузки.
- Сжатие папки средствами NTFS (WOF/LZX) и перенос папки на другой диск с точкой соединения на старом месте.
- Перетаскивание папки в окно и пункт «Анализировать в Простор» в контекстном меню Проводника.

**Очистка**
- Временные файлы, кэши браузеров и программ, корзина, журналы.
- Глубокая очистка: хранилище компонентов WinSxS, файл гибернации, точки восстановления, старые пакеты драйверов, установщики видеодрайверов, кэш установщика, журналы CBS/DISM.
- Исключения — папки, которые не трогает ни очистка, ни поиск.
- Очистка по расписанию через Планировщик заданий: Windows запускает `Prostor.exe --auto-clean`, программа чистит только безопасные категории, показывает короткое уведомление и закрывается.

**Автозагрузка**
- Программы, задания планировщика и службы.
- Отложенный запуск вместо отключения.
- Время загрузки Windows по журналу событий.

**Прочее**
- Журнал действий с отменой: восстановление из корзины, возврат автозагрузки, распаковка, перенос папки обратно, возврат записи в реестр.
- Тема по системе, светлая или тёмная, системный акцентный цвет, полупрозрачное окно (Mica) в Windows 11.
- Запоминание размера окна и последней страницы.
- Горячие клавиши: `Ctrl+1`…`Ctrl+6` — разделы, `Ctrl+,` — настройки, `F5` — обновить, `Ctrl+F` — поиск, `Delete` — удалить выбранное, `Backspace` или `Alt+←` — на уровень выше.
- Одна копия: повторный запуск (например, из меню Проводника) передаёт команду уже открытому окну.
- Проверка обновлений через GitHub Releases.

## Сборка из исходников

Нужен [Rust](https://rustup.rs) (stable) и Windows 10/11.

```powershell
cargo run             # запустить из исходников
cargo test            # тесты
.\build.ps1           # тесты и Release-сборка в папку dist
```

Часть тестов проверяет работу с настоящей Windows: корзину, реестр текущего пользователя, поиск остатков. Они создают записи с именами `Prostor Dummy…` / `prostor-…` и удаляют их после себя.

Для подписи перед `build.ps1` задайте переменные `PROSTOR_SIGN_PFX` (путь к сертификату .pfx) и `PROSTOR_SIGN_PASSWORD`. Нужен `signtool.exe` из Windows SDK.

Для разработки: `PROSTOR_DISPLAY=2` открывает окно на втором мониторе, `PROSTOR_SIZE=1600x1000` задаёт его размер.

## Выпуск версии

GitHub Actions (`.github/workflows/build.yml`) собирает и тестирует каждый коммит. Тег вида `v2.1.0` (совпадающий с `version` в `Cargo.toml`) создаёт релиз:

```powershell
git tag v2.1.0
git push origin v2.1.0
```

В релиз попадают `Prostor.exe` и тот же файл под именем `Prostor-lite.exe` — его скачивает облегчённая сборка версий 1.x, чтобы обновиться до 2.x.

Чтобы сборки подписывались, добавьте в секреты репозитория `SIGN_CERT_BASE64` (сертификат .pfx в Base64) и `SIGN_CERT_PASSWORD`.

Программа проверяет обновления в последнем релизе [GuiltHC/Prostor](https://github.com/GuiltHC/Prostor/releases) (другой репозиторий можно указать в «Настройки → Обновления»).

## Параметры командной строки

| Параметр | Что делает |
|---|---|
| `--page <раздел>` | открыть раздел: `dashboard`, `programs`, `analyzer`, `cleanup`, `startup`, `journal`, `settings` |
| `--scan <путь>` | сразу начать анализ папки или диска (путь можно передать и без параметра) |
| `--go <команда>` | внутренняя команда, например `program:Steam`, `programs:updates`, `settings:cleanup` |
| `--theme light\|dark` | тема на этот запуск |
| `--new-window` | открыть второе окно, а не переключиться на уже открытое |
| `--auto-clean` | очистка по расписанию без окна |

## Где хранятся данные

`%LocalAppData%\Prostor`:

- `settings.json` — настройки;
- `journal.json` — журнал действий;
- `disk-history.json` — история свободного места;
- `Scans\` — сжатые снимки сканирований для сравнения;
- `Backups\` — резервные копии ключей реестра и заданий;
- `error.log` — ошибки.

Чтобы сбросить программу, удалите эту папку.
