# Простор

Удаление программ и анализ места на диске для Windows 10/11. Скачать — в [релизах](https://github.com/GuiltHC/Prostor/releases/latest). Приложение запускается, когда оно нужно, и полностью закрывается вместе с окном: значка в трее и фоновых процессов нет.

## Возможности

**Программы**
- Классические программы, приложения Microsoft Store, игры Steam, Epic, GOG, EA, Ubisoft, Battle.net и Xbox в одном списке.
- Когда программу запускали последний раз (UserAssist, ярлыки «Пуск», Prefetch, Steam) и фильтр «Не используются».
- Метки: компонент (Visual C++, .NET и т. п.), драйвер, системная, предустановленная.
- Обновления через winget, кнопка «Обновить всё».
- Экспорт списка в CSV и в файл импорта winget.
- Точка восстановления перед удалением.
- Поиск остатков после удаления: папки, ключи реестра, задания планировщика, службы, ярлыки, автозагрузка, правила брандмауэра. Перед удалением ключи реестра и задания сохраняются в резервную копию.
- Принудительное удаление, если штатный деинсталлятор сломан или отсутствует.

**Анализ диска**
- Обычное сканирование и быстрое чтение MFT для NTFS (нужны права администратора).
- Диаграмма-плитка с приближением, подсветка по легенде, список крупных файлов.
- «Что выросло» — сравнение с прошлым сканированием.
- Дубликаты: сравнение по размеру, затем по хэшу начала и конца, затем по полному SHA-256; жёсткие ссылки не считаются копиями.
- Старые файлы и старые загрузки.
- Сжатие папки средствами NTFS (WOF/LZX) и перенос папки на другой диск с точкой соединения на старом месте.
- Перетаскивание папки в окно и пункт «Анализировать в Простор» в контекстном меню Проводника.

**Очистка**
- Временные файлы, кэши браузеров и программ, корзина, журналы.
- Глубокая очистка: хранилище компонентов WinSxS, файл гибернации, точки восстановления, старые пакеты драйверов, установщики видеодрайверов, кэш установщика, журналы CBS/DISM.
- Исключения — папки, которые не трогает ни очистка, ни поиск.
- Очистка по расписанию через Планировщик заданий: Windows запускает `Prostor.exe --auto-clean`, программа чистит, показывает короткое уведомление и закрывается.

**Автозагрузка**
- Программы, задания планировщика и службы.
- Отложенный запуск вместо отключения.
- График времени загрузки Windows по журналу событий.

**Обзор**
- Рекомендации: что можно освободить прямо сейчас.
- История свободного места с прогнозом, когда диск заполнится.
- Состояние дисков (SMART через Windows Storage).

**Прочее**
- Журнал действий с отменой: восстановление из корзины, возврат автозагрузки, распаковка, перенос папки обратно.
- Тема по системе, светлая или тёмная, системный акцентный цвет, фон Mica в Windows 11.
- Запоминание размера окна, последней страницы и сортировки.
- Горячие клавиши: `Ctrl+1`…`Ctrl+6` — разделы, `Ctrl+,` — настройки, `F5` — обновить, `Ctrl+F` — поиск, `Delete` — удалить выбранное, `Backspace` или `Alt+←` — на уровень выше.
- Проверка обновлений через GitHub Releases.

## Сборки

| Файл | Размер | Что нужно для запуска |
|---|---|---|
| `Prostor.exe` | около 60 МБ | ничего, .NET встроен |
| `Prostor-lite.exe` | около 2 МБ | [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) |

Если среды выполнения нет, `Prostor-lite.exe` при запуске предложит её скачать.

Из 24 МБ проекции Windows SDK программе нужны только `PackageManager` и `UISettings`, поэтому в Release-сборке эта библиотека урезается (остальные сборки, включая WPF, не трогаются). Урезать умеет только автономная публикация, поэтому lite-сборка берёт уже урезанную библиотеку у полной; `build.ps1` собирает их именно в таком порядке. Если собрать lite отдельно, в неё попадёт полная проекция, и файл будет весить около 25 МБ.

## Сборка из исходников

Нужен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```powershell
dotnet run --project Prostor            # запустить из исходников
dotnet test --project Prostor.Tests     # тесты
.\build.ps1 -Version 1.2.0              # обе сборки в папку dist
```

Системные тесты проверяют на настоящей Windows: принудительное удаление с поиском остатков, отложенный запуск, сжатие, перенос папки (каждое — вместе с отменой), меню Проводника и задачу автоочистки. Они создают в реестре текущего пользователя, папках профиля и Планировщике заданий записи с именами `Prostor Dummy…` и удаляют их после себя, поэтому запускаются только явно:

```powershell
dotnet test --project Prostor.Tests --filter-class Prostor.Tests.SystemTests --explicit only
```

Для подписи перед `build.ps1` задайте переменные `PROSTOR_SIGN_PFX` (путь к сертификату .pfx) и `PROSTOR_SIGN_PASSWORD`. Нужен `signtool.exe` из Windows SDK.

## Выпуск версии

GitHub Actions (`.github/workflows/build.yml`) собирает и тестирует каждый коммит. Тег вида `v1.2.0` создаёт релиз с обеими сборками:

```powershell
git tag v1.2.0
git push origin v1.2.0
```

Чтобы сборки подписывались, добавьте в секреты репозитория `SIGN_CERT_BASE64` (сертификат .pfx в Base64) и `SIGN_CERT_PASSWORD`.

Программа проверяет обновления в последнем релизе [GuiltHC/Prostor](https://github.com/GuiltHC/Prostor/releases) (другой репозиторий можно указать в «Настройки → Обновления») и скачивает файл с тем же именем, что у неё самой: `Prostor.exe` или `Prostor-lite.exe`.

## Параметры командной строки

| Параметр | Что делает |
|---|---|
| `--page <раздел>` | открыть раздел: `dashboard`, `programs`, `analyzer`, `cleanup`, `startup`, `journal`, `settings` |
| `--scan <путь>` | сразу начать анализ папки или диска |
| `--theme light\|dark` | тема на этот запуск |
| `--new-window` | открыть второе окно, а не переключиться на уже открытое |
| `--auto-clean` | очистка по расписанию без окна |

## Где хранятся данные

`%LocalAppData%\Prostor`:

- `settings.json` — настройки;
- `journal.json` — журнал действий;
- `disk-history.json` — история свободного места;
- `Scans\` — сжатые снимки сканирований для сравнения;
- `Backups\` — резервные копии ключей реестра и заданий;
- `error.log` — ошибки.

Чтобы сбросить программу, удалите эту папку.
